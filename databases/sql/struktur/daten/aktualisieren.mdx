title: "Aktualisieren"

---

Mit dem `UPDATE`-Statement kann man existierende Datensätze aktualisieren.

```sql
UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;
```

<Warning>
**Wichtig:** Die `WHERE`-Klausel muss unbedingt geschrieben werden, ansonsten werden alle Datensätze aktualisiert
</Warning>

## Beispiel

```sql
UPDATE Customers
SET ContactName = 'Alfred Schmidt', City = 'Frankfurt'
WHERE Id = 1;
```

Im Beispiel wird der Datensatz mit der CustomerId 1, modifiziert. Dabei wird der ContactName und City verändert.
