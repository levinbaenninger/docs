---
title: "Löschen"
icon: "trash"
---

Mit dem `DROP`-Befehl können wir Datenbanken und Tabellen löschen.

## Datenbank löschen

```sql
DROP DATABASE databasename;
```

### Beispiel

In folgendem Beispiel löschen wir eine Datenbank namens `my-db`.

```sql
DROP DATABASE my-db;
```

## Tabelle löschen

```sql
DROP TABLE table_name;
```

### Beispiel

In folgendem Beispiel löschen wir eine Tabelle namens `Shippers` und all die darin enthaltenen Daten.

```sql
DROP TABLE Shippers;
```
