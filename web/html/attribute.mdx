---

Elemente können auch Attribute haben. Attribute sehen so aus:

```html
<p class="editor-note">My cat is very grumpy</p>
```

Attribute enthalten zusätzliche Informationen über das Element, welches nicht im Inhalt erscheinen wird. In diesem Beispiel wird das `class` Attribut benutzt.

Ein Attribut beinhaltet:

* Ein Leerzeichen zwischen ihm und dem Elementnamen
* Den Attributnamen, gefolgt von einem `=`-Zeichen
* Ein Attributwert zwischen `"..."`

## Boolean Attribute

Manchmal sieht man Attribute ohne jeglichen Wert, das ist ein sogenanntes Boolean Attribut.

```html
<input type="text" disabled />
```
