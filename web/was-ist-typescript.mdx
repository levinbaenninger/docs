title: "Was ist TypeScript?"

---

**TypeScript** ist eine von Microsoft entwickelte **Programmiersprache**, die auf JavaScript basiert und dieses um **statische Typisierung** und moderne Sprachfeatures erweitert. TypeScript wird vor der Ausführung in reguläres JavaScript **kompiliert**, da Browser nur JavaScript verstehen.

TypeScript wird vor allem in grösseren Projekten verwendet, weil es:

* Typensicherheit bietet (z. B. Fehler beim Datentypen zur Entwicklungszeit erkennt)
* bessere Autovervollständigung und Code-Intelligenz in Editoren ermöglicht
* klare Schnittstellen mit interface oder type definieren kann
* moderne JavaScript-Features (ES6+) unterstützt, auch in älteren Browsern (via Transpiler)
* zu strukturierterem und wartbarem Code führt
