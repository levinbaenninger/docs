**CSS** steht für **Cascading Style Sheets** (deutsch: _gestufte Stilvorlagen_) und wird verwendet, um das Aussehen und Layout von HTML-Elementen zu gestalten. Während HTML für die Struktur zuständig ist, sorgt CSS dafür, dass Webseiten visuell ansprechend, benutzerfreundlich und responsive sind.

Mit CSS kann man:

* Farben, Schriftarten, Abstände und Ränder definieren.
* das Layout mit Grid oder Flexbox gestalten.
* Webseiten responsive machen, also an verschiedene Bildschirmgrössen (z. B. Smartphones) anpassen.
* Animationen und Übergänge einbauen.
* Styles wiederverwendbar machen und Webseiten pflegbar strukturieren.
