**JavaScript** (kurz: **JS**) ist eine **Programmiersprache**, die hauptsächlich im Browser eingesetzt wird, um Webseiten **interaktiv** und **dynamisch** zu machen. Während HTML den Inhalt liefert und CSS das Design festlegt, kümmert sich JavaScript um das Verhalten der Seite.

Mit JavaScript lassen sich unter anderem folgende Funktionen umsetzen:

* Benutzerinteraktionen (z. B. auf Klicks, Tastendrücke oder Formulareingaben reagieren)
* Inhalte dynamisch verändern (z. B. Text einblenden, Elemente verstecken)
* Daten von Servern abrufen und anzeigen (z. B. mit `fetch()` oder `XMLHttpRequest`)
* Animationen und visuelle Effekte erzeugen
* Formulare validieren
* Browserfunktionen nutzen (z. B. Geolocation, LocalStorage, Audio/Video-APIs)
