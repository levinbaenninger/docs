---
title: "Records"
icon: "table"
---

Records sind ein Datentyp in F#, um zusammengehörende Daten mit benannten Feldern strukturiert zu speichern. Sie sind kompakt, gut lesbar und werden vor allem für Datenmodelle verwendet.

Records sind standardmässig unveränderlich (immutable), das heisst, Werte werden nach der Erstellung nicht direkt geändert, sondern es wird ein neuer Record erzeugt.

```fsharp
type Person = {
    FirstName: string
    LastName: string
    Age: int
}

let person = {
    FirstName = "John"
    LastName = "Doe"
    Age = 30
}

printfn "%s %s is %d years old" person.FirstName person.LastName person.Age
```
