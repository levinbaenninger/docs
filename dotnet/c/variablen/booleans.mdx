C# hat einen `bool`-Datentyp, der die Werte `true` oder `false` annehmen kann.

```csharp
bool isCSharpFun = true;
bool isBroccoliTasty = false;
```

## Logische Operatoren

<Tabs>
<Tab title="AND-Operator">
Der AND-Operator gibt `true`  zurück, falls beide Statements `true` sind.

```csharp
x < 5 && x < 10;
```
</Tab>

<Tab title="OR-Operator">
Der OR-Operator gibt `true`  zurück, falls einer der beiden Statements `true` ist.

```csharp
x < 5 || x < 3;
```
</Tab>

<Tab title="NOT-Operator">
Der NOT-Operator invertiert das Resultat.

```csharp
!(x < 5 && x < 10);
```
</Tab>
</Tabs>
