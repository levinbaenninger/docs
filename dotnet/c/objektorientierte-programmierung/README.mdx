Objektorientierte Programmierung ist ein [Programmierparadigma](https://de.wikipedia.org/wiki/Programmierparadigma), welches Objekte und Klassen nutzt, um unser Program in zusammengehörige Properties und Verhaltensweisen zu teilen. 

## Klassen und Objekte

Eine Klasse ist eine Blaupause für ein Objekt. So kann zum Beispiel die Klasse `Fruit` die Skizze für `apple`, `pear`, `peach`, etc. sein.

```csharp
class Student
{

}

Student levin = new Student();
```
